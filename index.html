ECB 일별 기준환율을 사용합니다. ECB는 영업일 약 16:00 CET에 갱신하며 TARGET 휴무일에는 발표하지 않습니다. API 반영에는 지연이 있을 수 있습니다. 실시간 환율이 아니며 은행 현찰 매매율과 다릅니다.
